# gravity

Курс лекций, книга и вычислительные материалы NeutrinoHit по гравитации и
общей теории относительности. Рабочая рамка проекта — «ОТО для
экспериментаторов»: физическая наблюдаемая и измерительная процедура
предшествуют необходимому математическому аппарату.

Планируемый адрес сайта:

```text
https://neutrinohit.github.io/gravity/
```

## Структура

- `index.qmd` — стабильная домашняя страница курса;
- `ru/course.qmd` — программа курса и связь лекций с главами книги;
- `ru/book/` — исходники русской Quarto-книги (HTML, PDF, EPUB); на сайте книга
  не публикуется;
- `ru/slides/` — русские HTML-слайды;
- `ru/slides/assets/<lecture-slug>/` — код, рисунки и крупные фрагменты
  конкретной лекции;
- `shared/` — локальные копии общих RevealJS- и PDF-компонентов NeutrinoHit;
- `analytics/` — общий include аналитики.

Новые лекции добавляются как `ru/slides/<NN_slug>.qmd`. Общие параметры
RevealJS задаются один раз в `ru/slides/_metadata.yml`; в самой лекции должны
оставаться только её метаданные и содержание.

Главы книги находятся в `ru/book/chapters/`. Их порядок и группировка задаются
в `ru/book/_quarto.yml`. Слайды и книга развиваются параллельно, но не
генерируются друг из друга: связный вывод остаётся в книге, а визуальный сюжет
и интерактивная демонстрация — в лекции и её каталоге `assets/<lecture-slug>/`.

## Редакционный принцип

Каждая тема строится в одном порядке:

1. наблюдаемая величина и физический вопрос;
2. часы, сигнал, траектория или конкретный прибор;
3. минимальный математический инструмент;
4. вычислимое предсказание и область его применимости;
5. экспериментальная проверка, систематики, анимация и задачи.

## Сборка

```bash
make site
```

Готовый сайт записывается в `_site/`; книга в него не входит.

Книга отдельно, только локально (PDF собирается LuaLaTeX; `make ci-setup`
готовит TinyTeX и нужные пакеты):

```bash
make book-html
make book-pdf
make book-epub
```

`make book` собирает все объявленные форматы книги. `make help` показывает
полный набор целей.

Push в `main` автоматически публикует сайт. `workflow_dispatch` позволяет
повторить публикацию вручную.

Перегенерировать численные рисунки первой лекции:

```bash
python -m pip install -r requirements.txt
python ru/slides/assets/radial-signals/generate_figures.py
```

Обновить общие RevealJS- и книжные ресурсы из соседнего `neutrinohit-map`
(канонические скрипты `sync_reveal_assets.py` и `sync_book_assets.py`;
`make check-shared` только сравнивает копии):

```bash
make sync-shared
```

Анимации книги опубликованы на QR-страницах `https://neutrinohit.github.io/qr/gravity/<id>/`
по каталогу `neutrinohit-map/books/gravity.catalog.json`. QR-коды
(`ru/book/assets/qr/`) и постеры (`ru/book/assets/animations/`) обновляются
из каталога и ресурсов карты:

```bash
make book-media
```

Канонические CSS, Lua и TeX книжного оформления хранятся в
`neutrinohit-map/assets/books/`; в `gravity` находятся синхронизированные
локальные копии и только предметные дополнения.
